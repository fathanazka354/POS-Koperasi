Demo Chat ke Penjual (WebSocket)

Alur mirip Shopee/Tokopedia: pembeli buka thread per produk & penjual (karyawan), pesan realtime.

Login → buat percakapan → Connect WS → join dengan conversation_id → kirim message.

Buka demo di browser (tempel utuh, jangan ketik “PORT”):
http://localhost:8080/demo/chat
Angka 8080 harus sama dengan yang muncul di terminal saat make run (lihat APP_PORT di .env). Jika terminal menulis :8070, ganti jadi http://localhost:8070/demo/chat.

Safari: salin URL di atas (Cmd+V di bilah alamat). Jangan mengetik localhost saja. Jangan pakai teks PORT — itu hanya penanda dokumentasi, bukan bagian URL.

Anda membuka halaman dari file disk (file://). Browser sering memblokir fetch ke API. Jalankan server Go lalu buka di browser: http://localhost:8080/demo/chat (sesuaikan angka port dengan APP_PORT / output terminal).

Anda membuka HTML lewat Live Server / server statis (sering port 5500). Itu hanya melayani file, bukan API Go — POST ke sana hasilnya 405 Method Not Allowed. Jalankan make run, lalu isi Base URL API ke backend (mis. http://127.0.0.1:8080). Lalu buka halaman demo dari API Go: http://127.0.0.1:8080/demo/chat (ganti 8080 jika beda).
