Demo SPA — struktur aset (dibaca oleh Go embed all:demo)

index.html     Halaman utama (satu sumber untuk markup lengkap)
css/           base.css + landing.css / member.css / seller.css (override modul)
js/            Satu file per area (config, store, api, ui, …)
html/          Cuilan markup untuk referensi editor (sinkronkan manual dengan index jika diubah)
